About Tunisia Water Watch

An independent, satellite-based water and agriculture monitoring system for Tunisia. Built to run forever with zero maintenance, zero cost, and zero human intervention.

How it works

  1. Every 5 days, a GitHub Actions cron job triggers.
  2. The pipeline queries a public STAC API for the latest low-cloud Sentinel-2 scene over each dam's bounding box.
  3. Only the pixels inside the box are downloaded (COG range requests), typically <1 MB per dam.
  4. Green and near-infrared bands are combined into the Normalized Difference Water Index (NDWI = (G − NIR) / (G + NIR)).
  5. Pixels above a per-dam threshold are counted as water; the result is the reservoir surface area in km².
  6. The reading is appended to data/readings.csv, and this static site is regenerated and pushed.

What this is not

This is not volumetric measurement (which requires bathymetric survey). It does not detect underground pipe leaks, does not provide real-time flood warnings, and does not run weather models. Its value is continuity: it takes free satellite data that flies over Tunisia every 5 days, computes a simple water index, publishes the result, and accumulates a historical record — forever, for free, with no one needing to be involved.
